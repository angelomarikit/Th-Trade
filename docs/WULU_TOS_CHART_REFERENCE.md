# Thinkorswim chart reference (Wulu)

Reference screenshots show the target **professional terminal** layout:

| Pane | Content |
|------|---------|
| **Price** | Candlesticks + EMA(9) + Bollinger(20,2) + session VWAP |
| **Volume** | Histogram aligned to candles |
| **RSI** | RSI(14) with 30 / 70 guides |

**Not on chart:** entry, stop, target, or BUY labels — those stay in the **Scanner trade plan** only.

**WULU preview (`6009823+`):** stacked price / volume / RSI in one chart widget, clamped pan/zoom (no empty drag zones), compact right margin.

**Future (out of scope until Wulu approves):** multi-symbol flexible grid like TOS 2×2 — would be a separate milestone.
